# Лабораторна робота №6 — Системи контролю версій та SemVer

## Тема
Ініціалізація Git-репозиторію, стратегія гілкування GitFlow, вирішення merge-конфліктів та семантичне версіонування (SemVer 2.0.0).

## Файли
| Файл | Опис |
|------|------|
| `ОПІ_Добжанський_ЛР6_КН-24-1.docx` | Звіт лабораторної роботи |
| `project.gitignore` | Файл .gitignore для Node.js проєкту SmartInventory (виключення node_modules, .env, IDE файлів) |
| `database.config.js` | Конфігурація БД з вирішеним merge-конфліктом (компромісний таймаут 3000 мс) |
| `CHANGELOG.md` | Журнал змін проєкту за стандартом SemVer 2.0.0 (v1.0.0 → v2.0.0) |

## Завдання
- Ініціалізувати Git-репозиторій та налаштувати .gitignore
- Реалізувати стратегію гілкування GitFlow
- Продемонструвати вирішення merge-конфлікту
- Описати стратегію версіонування SemVer
