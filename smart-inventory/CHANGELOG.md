# Changelog — SmartInventory (SemVer 2.0.0)

Усі зміни в проєкті документуються за стандартом Semantic Versioning 2.0.0 (MAJOR.MINOR.PATCH).

## [v2.0.0] — Major Release
### Breaking Changes
- Перехід на нову версію API v2, повна заміна системи автентифікації на RBAC.

## [v1.1.0] — Minor Release
### Added
- Додано модуль автоматичного розрахунку собівартості за методом FIFO.

## [v1.0.1] — Patch Release
### Fixed
- Виправлено баг: некоректне відображення залишків при одночасних запитах.

## [v1.0.0] — Initial Release
### Added
- Базовий модуль обліку товарів, підтримка SKU та категорій прихід/видаток.
