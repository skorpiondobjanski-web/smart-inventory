## ПОРЯДОК І ЗМІСТ ВИКОНАННЯ ЗАВДАНЬ

### ЗАВДАННЯ 1. ПОСІБНИК КОРИСТУВАЧА СИСТЕМИ «SMARTINVENTORY»

#### 1.1. Вхід до системи та автентифікація
Для початку роботи із системою запустіть веб-браузер та перейдіть за адресою, наданою адміністратором системи (наприклад, `https://inventory.company.com`).

1. На екрані відобразиться вікно автентифікації.
2. Введіть вашу електронну пошту (логін) та пароль у відповідні поля.
3. Натисніть кнопку **«Увійти»**.
4. У разі успішної автентифікації система перенаправить вас на головну панель приладів (**Dashboard**). Права доступу до розділів меню будуть автоматично активовані згідно з вашою роллю (RBAC).

#### 1.2. Робота з каталогом товарів (Номенклатура)
Розділ **«Каталог товарів»** призначений для ведення списку продукції.
* **Додавання товару:**
  1. Перейдіть у меню **«Каталог» -> «Товари»**.
  2. Натисніть кнопку **«Додати товар»** у правому верхньому кутку.
  3. У формі, що відкрилася, заповніть обов'язкові поля: *Артикул (SKU)*, *Назва*, *Категорія*, *Ціна закупівлі*, *Ціна продажу* та *Мінімальний страховий запас*.
  4. Ви можете завантажити фотографію товару або згенерувати штрих-код автоматично кнопкою **«Згенерувати EAN-13»**.
  5. Натисніть **«Зберегти»**.
* **Пошук та фільтрація:** Використовуйте поле швидкого пошуку зверху таблиці для пошуку товарів за назвою, артикулом або штрих-кодом (підтримується зчитування сканером).

#### 1.3. Створення та проведення документів приходу (Оприбуткування)
Для внесення товарів, отриманих від постачальників, на баланс складу:
1. Перейдіть у розділ **«Документи» -> «Прихідні накладні»**.
2. Натисніть кнопку **«Створити прихід»**.
3. Оберіть склад оприбуткування та постачальника зі спадних списків.
4. У табличній частині натисніть **«Додати рядок»**, оберіть товар, вкажіть фактично отриману кількість та ціну закупівлі постачальника.
5. Натисніть **«Зберегти як чернетку»** для збереження роботи без оновлення залишків, або натисніть **«Провести документ»** для миттєвого оновлення залишків на складі.

### ЗАВДАННЯ 2. ПОСІБНИК СИСТЕМНОГО АДМІНІСТРАТОРА (DEPLOYMENT GUIDE)

Цей розділ описує процес розгортання та адміністрування веб-системи «SmartInventory» на сервері за допомогою технології контейнеризації **Docker** та інструменту **Docker Compose**.

#### 2.1. Системні вимоги до сервера
* **Операційна система:** Ubuntu Server 22.04 LTS або будь-який Linux дистрибутив з підтримкою Docker.
* **Процесор (CPU):** Мінімум 2 ядра (рекомендовано 4 ядра).
* **Оперативна пам'ять (RAM):** Мінімум 4 ГБ (рекомендовано 8 ГБ).
* **Сховище (SSD):** Мінімум 20 ГБ вільного місця.
* **Встановлене ПЗ:** Docker Engine >= 24.0, Docker Compose >= 2.20.

#### 2.2. Конфігурація оркестрації (Файл `docker-compose.yml`)
Для автоматичного запуску та координації чотирьох основних контейнерів системи (Frontend, Backend API, PostgreSQL, Redis) використовується наступний файл конфігурації:

```yaml
version: '3.8'

services:
  # 1. База даних PostgreSQL
  postgres_db:
    image: postgres:15-alpine
    container_name: smart_inventory_db
    environment:
      POSTGRES_USER: db_admin
      POSTGRES_PASSWORD: SecretSecurePassword2026
      POSTGRES_DB: smart_inventory
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    restart: always
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U db_admin -d smart_inventory"]
      interval: 10s
      timeout: 5s
      retries: 5

  # 2. Кеш-сервер Redis (сесії & аналітика)
  redis_cache:
    image: redis:7-alpine
    container_name: smart_inventory_redis
    ports:
      - "6379:6379"
    restart: always

  # 3. Сервер бізнес-логіки (Backend API)
  backend_api:
    image: smartinventory/backend:latest
    container_name: smart_inventory_backend
    environment:
      DATABASE_URL: postgresql://db_admin:SecretSecurePassword2026@postgres_db:5432/smart_inventory
      REDIS_URL: redis://redis_cache:6379
      JWT_SECRET: SuperGlobalJWTSecretKey2026
      PORT: 5000
    ports:
      - "5000:5000"
    depends_on:
      postgres_db:
        condition: service_healthy
      redis_cache:
        condition: service_started
    restart: always

  # 4. Клієнтська частина (Frontend)
  frontend_app:
    image: smartinventory/frontend:latest
    container_name: smart_inventory_frontend
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./ssl_certs:/etc/nginx/certs
    depends_on:
      - backend_api
    restart: always

volumes:
  postgres_data:
    driver: local
```

#### 2.3. Інструкція з розгортання системи
1. Створіть на сервері робочу директорію проєкту та перейдіть у неї:
   ```bash
   mkdir -p /opt/smart-inventory && cd /opt/smart-inventory
   ```
2. Створіть файл `docker-compose.yml` та скопіюйте в нього вищенаведену конфігурацію.
3. Скопіюйте ваші SSL-сертифікати (`fullchain.pem`, `privkey.pem`) в директорію `./ssl_certs` для забезпечення безпечного з'єднання HTTPS.
4. Запустіть розгортання системи в утилізованому (фоновому) режимі:
   ```bash
   docker compose up -d
   ```
5. Перевірте статус запущених контейнерів:
   ```bash
   docker compose ps
   ```
6. Виконайте первинну міграцію бази даних та створення адміністратора системи:
   ```bash
   docker compose exec backend_api npm run db:migrate
   docker compose exec backend_api npm run db:seed
   ```

#### 2.4. Резервне копіювання бази даних (Backup Strategy)
Для захисту даних від втрати налаштуйте автоматичний скрипт створення бекапів бази даних PostgreSQL. Створіть файл `/opt/smart-inventory/backup.sh`:

```bash
#!/bin/bash
BACKUP_DIR="/opt/smart-inventory/backups"
TIMESTAMP=$(date +"%Y%m%d_%H%M%S")
BACKUP_FILE="$BACKUP_DIR/db_backup_$TIMESTAMP.sql.gz"

mkdir -p $BACKUP_DIR
docker compose exec -T postgres_db pg_dumpall -U db_admin | gzip > $BACKUP_FILE

# Видалення бекапів, старіших за 30 днів
find $BACKUP_DIR -type f -mtime +30 -name "*.gz" -exec rm {} \;
```

Додайте скрипт до щоденного планувальника задач `cron` через `crontab -e`:
```text
0 2 * * * /bin/bash /opt/smart-inventory/backup.sh > /dev/null 2>&1
```
