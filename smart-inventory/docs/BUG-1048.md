# Bug Report #BUG-1048: Помилка розрахунку FIFO при нульовій собівартості

## Загальна інформація (Summary)
Відображення NaN замість вартості при списанні за FIFO для партій з нульовою ціною

## Опис проблеми (Description)
При створенні видаткової накладної для товарів з кількох партій, якщо одна з партій має
нульову собівартість (наприклад, безкоштовні зразки), система відображає NaN замість 0.00 грн.
Крім того, при експорті звіту у формат Excel виникає помилка 500.

## Кроки відтворення (Steps to Reproduce)
1. Відкрити картку товару «Noctua NH-D15» у складі товарів.
2. Натиснути «Створити видаткову → Списання за FIFO».
3. Ввести кількість для списання та підтвердити.

## Очікуваний результат (Expected Result)
Загальна вартість списання товару «Noctua NH-D15» відображається коректно як 0.00 грн.

## Фактичний результат (Actual Result)
Відображається NaN (Not a Number). Експорт звіту у XLSX формат завершується помилкою 500.

## Пріоритет (Priority)
**High (Високий)**. Впливає на фінансову звітність.

## Серйозність (Severity)
**Major (Значна)**. Помилка впливає на основну функціональність (фінансова звітність).

## Оточення (Environment)
- **ОС**: Ubuntu Server 22.04 LTS
- **Runtime**: Node.js 18.15.0
- **Браузер**: Google Chrome v121
