## Предметна область

**SmartInventory** — система управління складськими запасами, що підтримує:
- Облік товарів за SKU та категоріями
- Розрахунок собівартості за методом FIFO
- Сповіщення про низький рівень запасів (Low-Stock Alerts)
- Рольовий доступ (RBAC) для різних категорій користувачів
